# 旧URL（/agent）の互換性について

## 経緯
パスキーゲート導入前は、agentrouter を `https://<host>/agent/` で公開していた
（Tailscale Serve の `/agent` → 127.0.0.1:3081）。
現在は **`:8445` の専用オリジン**へ移動し、パスキー必須になっている。

## 現在の挙動（2026-11-08 実測）

| 旧URL | 応答 | 行き先 |
|---|---|---|
| `/agent` | **308** | `https://<host>:8445/` |
| `/agent/` | **308** | `https://<host>:8445/` |
| `/agent/api` | **308** | `https://<host>:8445/api` |
| `/agentx`（別名） | 302 | 通常のweb入口（パスキー後404） |

- 308はメソッドとボディを保持する恒久リダイレクト。**ブックマークはそのまま動く**。
- リダイレクト先は別ポート（別オリジン）になるため、**旧URLでインストールしたPWAは作り直しが必要**。
  新しいURL `https://<host>:8445/` で「アプリとしてインストール」し直す。
- 未認証で旧URLを開いた場合も、リダイレクト先で**パスキーを要求**される（保護は維持）。

## 推奨
- ブックマーク：新URL `https://<host>:8445/` へ更新（旧URLでも動くが二段階の遷移になる）
- PWA：新URLで再インストール
- `/agent` を恒久リダイレクトのまま残すか、将来削除するかは運用判断
